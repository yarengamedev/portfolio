Good to know

Questions studios ask me.

Do you work remotely?

Yes — remotely and full-time. I'm based in Girne, Cyprus (UTC+3) and work with teams across Europe and the US. I'm used to async updates, shared boards and clear written handovers.

Which engines and languages do you use?

Unity with C# and Roblox Studio with Lua/Luau are my main stacks. I also write C++ and HTML, and I use Git on every project.

Can you join a project that's already in progress?

That's a large part of what I do. I read the existing code first, match its structure and conventions, and start with small, reviewable changes before touching core systems.

What does working with you look like?

We agree on scope and milestones, then I send playable builds as I go — not just status messages. You always see the real thing running.

Are you open to a paid test task?

Yes. A small paid task is often the fastest way for a studio to see how I work, and it removes the risk of a long interview process.

Do you do full-time roles or only commissions?

Both. I'm open to full-time positions, long-term contracts and one-off commissions.

About me

Developer at heart, player in spirit.

I'm Yaren, a game developer based in Girne, Cyprus, currently working as a Game Developer at PARS Game and studying Computer Programming at Girne American University.

Since 2019 I've built 15+ games — on my own and for freelance clients — in Unity and Roblox Studio, writing C#, Lua and C++ along the way, handling the full development lifecycle — planning, prototyping, gameplay programming, UI/UX, asset integration and publishing.
